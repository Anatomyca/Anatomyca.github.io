# Anatomyca

A trilingual, offline-capable, mobile-first 3D map of the human body, for
Sri Lankan students, teachers and patients. Turn the model, tap a bone or an
organ, and read what it does — with the name in English, Sinhala and Tamil.

Static site, no backend, no accounts, no tracking. All personal state
(bookmarks, progress) stays in the reader's own browser.

## What works today

- **Forty-one structures across nine systems**, drawn as procedural geometry,
  so the first visit is **0.97 MB** and the atlas works with no mesh download
  at all.
- **Trilingual throughout.** Interface and structure names in English, Sinhala
  and Tamil, switchable at any time, with Latin terms alongside.
- **Search across all three scripts**, plus everyday synonyms and romanised
  input — a student who types `hadawatha` on an English keyboard finds the
  heart.
- **Accuracy grades on every structure** (see below).
- **Shareable deep links**: `#/s/heart?lang=si` opens on the heart, in
  Sinhala.
- **Installable and offline** after the first visit.

## Accuracy, honestly

No 3D atlas is 100% accurate, and the reviewed datasets this project builds on
say so themselves. Human anatomy varies; every model traces back to one body;
and naming is often a judgement rather than a fact.

So the promise is not "100% accurate". It is that **every structure's
provenance and review status is visible**, which is a claim you can check:

| Grade | Meaning | Source |
|---|---|---|
| **A** | Reviewed by subject-expert anatomists | Open3Dmodel |
| **B** | Published reference dataset, not individually expert-reviewed | BodyParts3D, Z-Anatomy, HuBMAP |
| **C** | Teaching shape in a correct position, generated by this project | Anatomyca procedural |

Everything in the current release is Grade C. Imported meshes supersede it
structure by structure. Sinhala and Tamil names are marked *provisional*
until two named reviewers per language have signed them off — the build fails
if anything claims review without a reviewer.

## Run it

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # static output in dist/
npm test             # unit tests
npm run e2e          # end-to-end, five viewports
npm run check        # typecheck and lint
```

## Bringing in the upstream anatomy

The BodyParts3D tables and archives are fetched separately, never committed —
the IS-A archive is 136 MB, past GitHub's 100 MB hard limit.

```bash
npm run atlas:fetch -- --tables-only   # the six tables (~2.2 MB)
npm run atlas:hierarchy                # IS-A and PART-OF trees, compound → element
npm run atlas:validate                 # licence, terminology and coverage gates
```

`npm run atlas:fetch` without `--tables-only` also pulls the two geometry
archives into the git-ignored `data-cache/`.

## How it is put together

```
src/domain/      the term schema and accuracy grades
src/data/        the forty-one seed structures, with trilingual names
src/three/       procedural geometry, and the three.js viewer
src/search/      script-aware normalisers and the MiniSearch index
src/i18n/        per-language string bundles, loaded on demand
src/state/       store and hash-based deep links
src/ui/          React components, mobile-first
src/lk/          Sri Lanka-specific layers (offline storage, and more to come)
scripts/         the data pipeline and the CI gates
docs/adr/        why things are the way they are
```
