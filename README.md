# Anatomyca

A trilingual, offline-capable, mobile-first 3D map of the human body, for
Sri Lankan students, teachers and patients. Turn the model, tap a bone or an
organ, and read what it does — with the name in English, Sinhala and Tamil.

Static site, no backend, no accounts, no tracking. All personal state
(bookmarks, progress) stays in the reader's own browser.

## What works today

- **The whole BodyParts3D body**: 2,234 individually selectable meshes across
  fifteen systems, 2.29 million triangles, with 3,432 named FMA concepts.
- **Concepts, not just meshes.** "Heart" has no mesh of its own — it is a
  concept gathering 83 element meshes. Searching for it finds it and selects
  all 83; tapping a mesh shows the organs it belongs to, one tap away.
- **One download per system.** The geometry is re-chunked by body system, so
  a first visit costs about 9 MB for a recognisable body and the vascular
  trees, muscles and nerves stream only when asked for.
- **Trilingual interface** in English, Sinhala and Tamil, switchable at any
  time, with Latin terms where they are known.
- **Search across all three scripts**, plus romanised input — a student who
  types `hadawatha` on an English keyboard finds the heart.
- **Accuracy grades on every structure** (see below).
- **Shareable deep links**: `#/s/FMA7088?lang=si` opens on the heart, in
  Sinhala.
- **Anatomist-reviewed study models** for the skeleton and skull, including
  an exploded skull and individually named teeth.
- **Installable and offline** after the first visit.
- **Built for a phone.** Every panel is reachable from a bottom bar, the
  body keeps the screen until something is asked for, and the layout holds
  at 320px in all three languages.

## What the dataset does and does not contain

BodyParts3D 4.0 is an adult male reference body. It is thorough in most
places and empty in a few, and the interface says which is which rather than
leaving a reader to guess:

| System | In this release | Missing |
|---|---|---|
| Nervous | 96 brain structures, spinal cord, 40 orbital nerves | **All peripheral nerves** — sciatic, vagus, facial, median, brachial plexus |
| Endocrine | Pituitary, pineal, both adrenals | Thyroid, parathyroid |
| Lymphatic | Spleen, both thymus lobes | Lymph nodes and vessels |
| Reproductive | Male only | Ovaries, uterus, and the rest of female anatomy |

Every system carrying a gap shows a note naming it, and naming the open
dataset that would close it — Open3Dmodel for the limb nerves and the head
and neck, HuBMAP for the female body.

Where BodyParts3D names only halves — "right lung", "left lung", but no
"lung" — the whole organ is derived from the pair and carries a `PAIR-` id.
Ninety-nine organs are reachable this way that otherwise were not, including
the lungs, eyes, hands and feet.

## Accuracy, honestly

No 3D atlas is 100% accurate, and the reviewed datasets this project builds on
say so themselves. Human anatomy varies; every model traces back to one body;
and naming is often a judgement rather than a fact.

So the promise is not "100% accurate". It is that **every structure's
provenance and review status is visible**, which is a claim you can check:

| Grade | Meaning | Source |
|---|---|---|
| **A** | Reviewed by subject-expert anatomists | Open3Dmodel — 5 study models, 234 structures |
| **B** | Published reference dataset, not individually expert-reviewed | BodyParts3D, Z-Anatomy, HuBMAP |
| **C** | Teaching shape in a correct position, generated by this project | Anatomyca procedural |

The atlas holds two kinds of body, and the picker says which is which:

- **The whole body** — BodyParts3D, 2,234 structures across every system.
  Grade B: a published reference dataset, not individually reviewed.
- **Five study models** — Open3Dmodel, 234 structures. Grade A: every one
  reviewed by subject-expert anatomists. The full named skeleton, the skull
  coloured, exploded and as a cranial base, and three vertebrae compared.

They are kept separate rather than merged: the two stand 1.70 m and 1.75 m
and segment the skeleton differently, so overlaying them would double every
bone slightly out of register. See `docs/adr/0005`.

On names, be aware of the real gap: BodyParts3D supplies **English only**.
Sinhala and Tamil names come from this project's own list and currently reach
**35 of 3,432 concepts**. Every other structure shows its English name, and
the interface says so. No term is marked reviewed without a named reviewer —
the build fails if anything claims otherwise.

## Run it

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # static output in dist/
npm test             # unit tests
npm run e2e          # end-to-end, five viewports
npm run check        # typecheck and lint
```

## Working with the geometry

The shipped chunks are committed, so a clone needs no downloads. The
pipeline below only matters if you are re-importing or extending the anatomy.

```bash
npm run atlas:chunk      # regroup geometry into one chunk per body system
npm run atlas:validate   # atlas, terminology, licence and coverage gates
```

To pull the original BodyParts3D tables (the six hierarchy files, ~2.2 MB)
for the IS-A and PART-OF trees:

```bash
npm run atlas:fetch -- --tables-only
npm run atlas:hierarchy
```

The raw geometry archives are never committed — the IS-A archive alone is
136 MB, past GitHub's 100 MB hard limit — so `npm run atlas:fetch` without
`--tables-only` puts them in the git-ignored `data-cache/`.

## How it is put together

```
src/domain/      the term schema and accuracy grades
src/atlas/       manifest, batched renderer, scene, concept resolution
src/data/        the trilingual seed names and their upstream variants
src/search/      script-aware normalisers and the MiniSearch index
src/i18n/        per-language string bundles, loaded on demand
src/state/       store and hash-based deep links
src/ui/          React components, mobile-first
src/lk/          Sri Lanka-specific layers (offline storage, and more to come)
scripts/         the data pipeline and the CI gates
docs/adr/        why things are the way they are
```
